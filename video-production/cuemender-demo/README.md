# CueMender submission film

Editable HyperFrames composition for the silent 165-second hackathon demonstration. This folder is production material, not an application runtime dependency.

Pinned CLI: HyperFrames 0.8.221. `npm run dev`, `npm run check`, `npm run render` use the package scripts. Original and derived screen recordings are intentionally excluded from Git; see CAPTURE-MANIFEST.md for local provenance and timing. Restoring those named media files is required to rerender the source composition.

Read BRIEF.md, SPEC.md, STORYBOARD.md and REVIEW.md before changing the film. Persistent real/offline/read-only and rehearsal labels are intentional. Do not replace real footage with generated UI or relabel simulated repair as live evidence.

The current revision matches the user's ErrataScope demo visual system. `python scripts/build-composition.py` regenerates the fourteen scenes from the copied reference CSS and CueMender-specific content. REFERENCE-ANALYSIS.md records the comparison and source provenance. The pale first cut is superseded and not approved for publication.

Local final output: `renders/cuemender-demo-final.mp4`. The delivery receipt records verified encoded properties and checksum after rendering. Public links belong in docs/submission once publication is confirmed.

Third-party runtime/font terms are in ASSET-NOTICES.md. No audio is intentional.
